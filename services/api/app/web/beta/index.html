01 / 식사 기록

찍고, 한 번 확인하면
식사 기록 끝.

사진 속 음식을 AI가 살펴보고 칼로리와 영양소를 추정해요. 밥 양처럼 중요한 부분은 직접 확인하고, 결과를 고쳐 저장할 수 있어요.

  • 카메라와 사진첩으로 간편하게
  • 단정값 대신 칼로리 범위와 분석 근거
  • 확인·수정 후 오늘의 식사로 저장

사진만으로 모든 재료·양을 알 수는 없어요. 결과는 추정치이며 의료·영양 진단이 아닙니다.

사진 분석 결과 예시580–720 kcal

밥 양을 확인하면 범위를 좁힐 수 있어요.

02 / 단백질과 목표

몇 칼로리보다,
오늘 무엇을 더 챙길지.

내 목표에 맞춘 칼로리와 단백질 권장량을 확인해요. 기록한 식사의 섭취량과 남은 양을 함께 볼 수 있어요.

  • 감량·유지·근육 증가에 맞춘 목표
  • 칼로리와 탄수화물·단백질·지방 누적
  • 체중·회복 체크인과 주간 기록 확인

목표와 수치는 일반적인 계산에 따른 참고 정보예요. 개인의 질환이나 치료를 반영한 처방이 아닙니다.

오늘의 단백질 · 예시82 / 120 g82 / 120

다음 식사에서 38g을 더 챙겨볼까요?

03 / 운동 루틴과 기록

다음 운동을 정하고,
한 세트씩 쌓아가요.

목표와 운동 빈도, 가능한 장비를 바탕으로 루틴을 확인해요. 운동별 중량·반복·세트를 기록하고 지난 수행을 돌아봐요.

  • 목표·경험·장비·시간을 반영한 계획
  • 세트별 중량·반복 횟수 기록
  • 식사와 운동의 흐름을 주간 코치로 확인

현재 운동 추천은 규칙 기반이에요. 전문 트레이너의 실시간 지도나 의료 상담을 대신하지 않습니다.

운동 기록 예시오늘은 상체 운동

시작하기 전에

궁금한 점을 모았어요.

누가 참여할 수 있나요?

만 18세 이상이며 Android 휴대폰으로 테스트할 수 있는 분이 참여할 수 있어요. 신청에는 연락용 이메일을, 앱 로그인에는 본인의 카카오 계정을 사용해요. 두 이메일이 같아야 하는 것은 아닙니다.

무료인가요? 카드 등록이 필요한가요?

현재 베타 참여에는 결제수단 등록이 필요 없어요. 정식 출시 일정과 요금은 별도로 안내하며, 베타 신청으로 유료 구독이 시작되지 않아요.

플레이스토어나 Expo Go에서 받나요?

지금은 신청 완료 화면의 APK 링크로 직접 설치해요. Expo 계정·Expo Go·개발 서버는 필요 없어요. Play 스토어 테스트가 준비되면 별도로 안내합니다.

APK는 어떻게 설치하나요?

Android의 Chrome에서 설치 링크를 열고 Expo 화면의 Install 또는 Download build를 눌러요. 내려받은 .apk 파일을 열면 설치할 수 있어요. 출처 허용을 요청하면 해당 브라우저·파일 앱의 설치 권한만 확인해 주세요. 설치 후에는 다시 차단해도 됩니다. Play Protect 같은 보안 기능은 끄지 마세요. 검사 실패나 예기치 않은 경고가 나오면 설치를 멈추고 오류 화면을 문의 이메일로 보내주세요.

몸 사진도 AI가 분석하나요?

신체 사진 체크인은 준비 중인 기능이며 현재 결과는 실제 사진을 본 AI 분석이 아닙니다. 이번 베타는 음식 기록, 영양 목표, 운동 기록을 중심으로 확인해 주세요. 신청 페이지에서는 건강정보나 사진을 받지 않아요.

이메일로 설치 링크가 오나요?

현재는 신청 완료 화면에서 링크를 바로 제공해요. 자동 안내 메일을 보냈다고 표시하지 않으며, 이메일 소유권이나 Play 테스터 등록을 자동 확인하지 않아요.
