# Design Reference Research

## 2026-07-17 - Cal AI cute trust-first mobile direction

### Product job

Help Korean 20s-30s users log a meal from a photo every day without feeling judged, while still showing enough uncertainty, correction, and evidence to trust the nutrition result.

### Design read

A cute-but-credible Korean nutrition logger: fast photo logging, warm food-first visuals, soft character accents, and trust-first analysis cards that show calorie ranges, confidence, and one small correction question.

### Dials

- `DESIGN_VARIANCE`: medium-high from the current Warm Trust Nutrition direction
- `MOTION_INTENSITY`: medium-low, sticker-like delight without turning the app into a game
- `VISUAL_DENSITY`: medium, enough nutrition data for trust while keeping daily use light

### References inspected

### Direction decision

The next visual concept should not become a dark, mascot-only marketing poster. It should look like a real mobile product screen first: warm ivory surfaces, food photography, tidy nutrition cards, one small mascot/helper accent, and friendly Korean copy. The character should make the app less stiff, while the analysis UI should keep trust through ranges, confidence, assumptions, and editable portion clarification.
