## Limits and restoration

manual handler check. The existing daily job must be monitored; expiry is followed
by cleanup, not a promise of simultaneous removal of logs/backups. The synthetic
application is subject to that same policy.

experience, set it to `true` and redeploy. `/beta` remains available as landing.
The original Expo export and private generated shell are preserved by the build.
This hides web entry points; it does not make public frontend asset bundles secret.
